本地部署 Deepseek R1 未经审查(无限制)模型

lololowe2025-02-052026-08-05

1. 前言

本地部署 DeepSeek 的优势是无需联网使用，并且所有数据都在本地，非常安全，没有隐私问题，更重要的是没有网络审查机制，询问敏感问题时不会拒绝回答或者回答到关键点时停止，但也仅仅是少了网络审查，模型还有内置的审查机制，同样会拒绝回答用户的一些问题。

而使用abliteration技术创建的未经审查(uncensored)版本的大模型，移除了模型的拒绝机制，除此外部署方式和原版的一模一样，都是通过ollama拉取模型，然后运行。

2. 部署

2.1. 安装ollama

ollama是一个开源的LLM（大语言模型）运行框架，可以运行各种大语言模型，包括深度求索的Deepseek R1、Meta的llama、 阿里的qwen等等。

ollama的官方下载地址为：https://ollama.com/download

根据自己的操作系统选择对应的版本下载即可。安装完成后打开命令行，输入ollama -v即可确认安装是成功：

由于ollama服务器在国外，因此下载可能会很慢，推荐使用魔搭社区的镜像加速下载。进入下面的网页，点击master下拉框，选择最新的版本，下载对应的版本即可：
https://modelscope.cn/models/Lixiang/ollama-release/files
Linux版下载下来后需要解压两次：zstd -d ollama-linux-amd64.tar.zst && tar -xvf ollama-linux-amd64.tar，最后进入bin目录后运行./ollama即可启动ollama。
ollama 软件本体默认装在C盘，推荐用命令行指定安装位置为D盘：.\OllamaSetup.exe /DIR="D:\ollama\"
ollama AI模型默认下载到C盘，可以参考此文章修改存放位置: https://blog.powersee.top/2024/08/ollama-models-path/

ollama最初是一个命令行工具（现已支持GUI操作），其命令比较类似于docker，常用的命令如下：

ollama运行后会自动将API地址设置为http://127.0.0.1:11434，并且也兼容OpenAI的API接口，使用路径为：http://127.0.0.1:11434/v1/chat/completions。

推荐3个可以调用ollama的API接口的图形化工具：

  • Cherry Studio(应用程序): https://cherryai.com.cn/download
  • Chatbox(应用程序): https://chatboxai.app/zh/install?download=win64
  • Page Assist(浏览器扩展): https://github.com/n4ze3m/page-assist

2.2. 拉取并运行未经审查模型

根据自己电脑的配置，参考下图选择合适的模型进行下载和运行，RTX 4060 Laptop建议跑8b参数版本：

模型大小 拉取命令
8b ollama run modelscope.cn/mradermacher/Josiefied-DeepSeek-R1-0528-Qwen3-8B-abliterated-v1-i1-GGUF
8b ollama run modelscope.cn/mradermacher/NSFW-FFS-w-hidden-Deepseek-Distill-NSFW-Redux-i1-GGUF
14b ollama run nexusriot/deepseek-r1-abliterated:14b
14b ollama run modelscope.cn/mradermacher/DeepSeek-R1-Distill-Qwen-14B-abliterated-v2-remap-i1-GGUF
32b ollama run modelscope.cn/featherless-ai-quants/NaniDAO-deepseek-r1-qwen-2.5-32B-ablated-GGUF
70b ollama run modelscope.cn/ThalisAI/DeepSeek-R1-Distill-Llama-70B-heretic
70b ollama run huihui_ai/deepseek-r1-abliterated:70b

推荐一个网站，可以自动检测本机硬件参数并推荐适合部署的大模型：https://www.canirun.ai/?q=deepseek

2.3. 对比测试

用同一个问题测试在线版本、官网API版本、本地原版、本地未经审查版本，对比结果如下：

  1. 在线版本：拒绝回答

  1. 在线API版本：拒绝回答

  1. 本地部署原版：拒绝回答

  1. 本地部署未经审查版本：正常回答

更多测试拒绝行为的提示词可以看这里：https://github.com/llm-attacks/llm-attacks/blob/main/data/advbench/harmful_behaviors.csv

3. 其他

除了deepseek的去审查模型，也可以通过搜索这几个关键词，在huggingface、ollama和阿里云魔搭社区上查找其他的未经审查模型：abliterated、ablated、heretic、uncensored
